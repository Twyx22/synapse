# Synapse v1.0.0

First major release of Synapse, a local collaborative agent runtime for OpenCode V2. It brings the graph scheduler, project memory, independent reviews, economic analysis and provider failure handling into one plugin.

## Highlights

- Cooperative disk locks for graph updates and execution admission, and for evolution proposal updates.
- `synapse_doctor` and `npm run doctor` for local runtime, storage and ledger checks.
- Separate functional completion from economic eligibility; failed runs and missing usage no longer count as evidence of economic performance.
- Private backup of the initialized target store during release upgrades, without overwriting other project stores.

Existing schema-1 records remain readable. No new npm dependency or mandatory schema migration is introduced by 1.0.0.

## Validation and limitations

The local suite contains 164 tests, including independent-process contention and provider failure simulations. The core TypeScript check passed. A real Linux OpenCode V2 diagnostic confirmed activation of 1.0.0, retained project records and the economic eligibility changes. Full SDK typechecking and a current npm dependency audit have not been independently completed in the packaging environment. A successful controlled Lean benchmark and a complex real-world reviewed coding mission remain outstanding. This is a release milestone, not a production certification.

Use one OpenCode writer per project; locks are cooperative, local and limited in scope. Session budgets are not spending caps. Workers are read-only; reviewed patches require manual staging. See the README and `docs/V1.md` for details.

## Install

Download the source ZIP and matching installer, verify their checksums, finish active runs and close OpenCode. On Linux:

```sh
bash install-synapse-v1.0.0.sh Synapse-OpenCode-v1.0.0.zip
```

Run `npm run health`, then check `synapse_version` in a new OpenCode session. Keep installation paths stable and back up relevant project stores before upgrading.
