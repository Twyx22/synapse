# Getting help

Start with [the installation guide](docs/INSTALLATION.md) and [diagnostics](docs/DIAGNOSTICS.md). For a reproducible bug, use the bug report issue template. For a feature request, explain the problem you are trying to solve.

Include Synapse, OpenCode and Node versions, the operating system, and relevant sanitized error output. Do not paste full configuration files or private run data. `npm run doctor` and `npm run health` can help narrow down the issue without launching a model. There is no guaranteed support SLA.
