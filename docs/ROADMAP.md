# Roadmap

The 1.0 release establishes the local graph runtime, contracts, reviewed results, project storage, provider resilience and accounting. The next priority is qualification, not a larger feature list.

## Near term

- Run the full SDK typecheck and dependency audit with the installed V2 SDK; commit a reviewed lockfile.
- Validate a successful standard/Lean comparison with the same provider and model settings.
- Exercise a complex reviewed coding mission and multi-agent provider circuit behavior on the real host.
- Improve coverage for process failure and operational recovery.

## Longer term

- Evidence-based model and team recommendations, with opt-in execution and explicit cost controls.
- Better project-local retrieval and optional, explicitly authorized transfer between projects.
- Shared resource coordination across instances, including uncertain remote interruptions.
- Improved observability and isolated contribution verification.

These are proposals, not commitments or features already shipped. Changes that affect review, permissions, spend or data scope need explicit approval and regression tests.
